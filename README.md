# Cloud Portfolio Labs

Laboratório prático de infraestrutura, Linux, Cloud Operations,
DevOps e automação.

## Objetivo

Construir projetos técnicos para desenvolver e demonstrar
competências em administração de servidores, infraestrutura,
monitoramento e automação.

## Projetos

| Projeto | Descrição | Status |
|---|---|---|
| 01 - Linux Cloud Operations | Administração e diagnóstico de servidores Linux | Em desenvolvimento |
| 02 - Infrastructure as Code | Provisionamento com Terraform | Planejado |
| 03 - Containers and Services | Docker e serviços conteinerizados | Planejado |
| 04 - Monitoring and Observability | Métricas, logs e alertas | Planejado |
| 05 - Cloud Automation and DevOps | Python, APIs e pipelines | Planejado |

## Ambiente atual

- Host: Windows 11
- Virtualização: Oracle VirtualBox
- Sistema convidado: Ubuntu Server 24.04.5 LTS
- Acesso remoto: OpenSSH
- Rede: NAT
- Versionamento: Git

## Primeiro projeto: Linux Cloud Operations

O primeiro laboratório aborda:

- Inventário de servidores Linux
- Administração de usuários e permissões
- Gerenciamento de serviços
- SSH e segurança
- Redes e firewall
- Logs e troubleshooting
- Automação com Shell Script

## Princípios

- Implementação prática e documentada.
- Testes e validação de cada configuração.
- Cenários fictícios, sem dados de ambientes corporativos.
- Uso local sempre que possível para evitar custos de nuvem.

**Nota:** este repositório documenta um laboratório local. Não representa
uma infraestrutura implantada em Azure ou AWS.
