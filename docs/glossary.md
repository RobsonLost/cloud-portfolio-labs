# Glossary

| Termo | Definição |
|---|---|
| VM | Máquina virtual |
| SSH | Protocolo de acesso remoto seguro |
| NAT | Tradução de endereços de rede |
| systemd | Sistema de inicialização e gerenciamento de serviços |
| UFW | Firewall simplificado do Ubuntu |
| Kernel | Núcleo do sistema operacional |
| IaC | Infrastructure as Code |
| Troubleshooting | Processo de diagnóstico e resolução de problemas |
